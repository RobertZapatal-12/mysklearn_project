## Version 1 of the project

This is version 1 of the project, which includes only one model: linear regression. The goal of this first release is to keep a simple and clear structure focused on the fundamental concepts of supervised learning.

### Includes

- Linear regression model
- Basic training functions: fit
- Basic prediction functions: predict
- Metrics available in the metrics module:
  - mean_absolute_error
  - mean_squared_error
  - root_mean_squared_error
  - r2_score

### Overview

This project is designed as an educational and minimalist implementation of a linear regression model, along with a set of metrics to evaluate its performance. In this version, only linear regression is included as the main model, without extensions or additional models.

### Project structure

- mysklearn/
  - metrics/
    - __init__.py
    - metrics.py

### Objective

To provide a lightweight and understandable foundation for understanding how a linear regression model works, how it fits the data, and how its performance is evaluated using standard regression metrics.

---

This project represents the first functional and focused version on linear regression, with a limited but useful set of tools for training, prediction, and evaluation.
